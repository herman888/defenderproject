# Gallery

Screenshots, CAD, sim captures, and field photos go here. Add images under `site-docs/gallery/` and link them below.

---

## How to add an image

1. Put the file in `site-docs/gallery/` (e.g. `sim-dashboard.png`)
2. Reference it in Markdown:

```markdown
![Sim dashboard](sim-dashboard.png)
```

3. Save — `mkdocs serve` live-reloads
