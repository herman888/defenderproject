# Core runtime for the simulator and the test suite.

# Pinned deliberately. Unpinned ranges made this a "works on my machine" build:
# a contributor installing next month would get a different NumPy or PyBullet
# than the one every published measurement was taken on.
#
# `pyproject.toml` is the source of truth; this file mirrors its core
# dependency set so `pip install -r requirements.txt` keeps working.
# `requirements.lock` is the exact, fully-resolved environment.

#   pip install -e .[ml]      guidance-policy training (deferred - see AGENTS.md)
#   pip install -e .[vision]  camera detection pipeline
#   pip install -e .[docs]    MkDocs site
#   pip install -e .[dev]     pytest
